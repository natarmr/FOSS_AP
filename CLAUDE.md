This repo is the **promotional website for FOSS SRMAP at SRM University AP**. It's a Next.js 16 (App Router) teaser site.

- **Stack:** Next.js 16, React 19, Tailwind v4, TypeScript. Dev runs on port 3001.
- **Routes:** `/` (teaser — parental-advisory gate, background soundtrack, "time wasted" counter) · `/poap` (the "POAP?" troll + contribute page) · `/speakers` · `/sponsors` · `/partners`.
- **Repo:** https://github.com/natarmr/FOSS_AP (public)
